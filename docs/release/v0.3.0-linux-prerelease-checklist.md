# v0.3.0 Linux Draft Prerelease Checklist

Milestone: `V030-RELEASE-PREPARATION1`

Release tag: `v0.3.0`

This checklist prepares an unpublished Linux-first draft prerelease. It does not mark Calcwiz as production-stable or claim full computer algebra system parity.

Reusable release process:
- [Release process](release-process.md)

## Local Release Evidence

Run with the repository-approved Node 24 toolchain:

```bash
npm ci
npm run test:launch-preflight
npm run test:ci-gate-alignment
npm run build
cargo check --manifest-path src-tauri/Cargo.toml
npm run tauri:build
```

Inspect the generated bundles under `src-tauri/target/release/bundle/`:

- [x] AppImage exists, has the expected Calcwiz name/version, and is recognized as an executable Linux image.
- [x] Debian package exists, reports version `0.3.0`, and contains the expected desktop application metadata.
- [x] RPM package exists, reports version `0.3.0`, and contains the expected desktop application metadata.
- [x] The inspected v0.3.0 artifacts are non-empty, freshly built, and share this checkout's release source.

## Create The Draft

After the main CI checks above are green and separate tag approval is received:

```bash
git tag v0.3.0
git push origin v0.3.0
```

- [ ] Wait for the tag-triggered `Release Linux` workflow.
- [ ] Confirm the GitHub release remains `draft: true` and `prerelease: true`.
- [ ] Confirm AppImage, Debian, and RPM files are attached to the draft.
- [ ] Do not publish yet.

## Artifact Smoke Before Publication

On a supported Linux host:

- [ ] Launch the AppImage and confirm the app opens without crashing.
- [ ] Install and launch the Debian package on a compatible Debian/Ubuntu environment.
- [ ] Install and launch the RPM package on a compatible RPM-based environment.
- [ ] Run a basic Calculate expression such as `2+3`.
- [ ] Run complete derivative notation such as `d/dx(x^3+2x)`.
- [ ] Run an indefinite integral such as `\int 1/(1+x^2)\,dx`.
- [ ] Solve `x^2-1=0` and inspect the exact roots, details, copy result, and History replay.
- [ ] Close and reopen the app and confirm startup remains healthy.
- [ ] Confirm README/release wording remains Linux-first, bounded, MIT-licensed, and not full CAS parity.

Publishing the draft is a separate manual decision after all artifact smoke checks pass.

## Rollback

If the draft or artifacts are wrong, do not publish. Correct the release commit, rerun main CI, and request a new tag decision. If the unpublicized tag itself must be replaced:

```bash
git tag -d v0.3.0
git push origin :refs/tags/v0.3.0
```
